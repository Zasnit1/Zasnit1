# Hi, I'm Ibrahim Maqtoush

Application & program bug hunter, focused on offensive security, web application security and vulnerability research. I like small, sharp tools that do one security job well.

### Open-source security tools

| Tool | What it does |
|---|---|
| [kev-watcher](https://github.com/Zasnit1/kev-watcher) | Monitor the CISA Known Exploited Vulnerabilities catalog for the vendors and products in your stack |
| [secheaders](https://github.com/Zasnit1/secheaders) | Audit a website's HTTP security headers, cookie flags and CORS policy, with a score and grade |
| [jsrecon](https://github.com/Zasnit1/jsrecon) | Extract endpoints and likely leaked secrets from JavaScript files (offline, parses files only) |
| [osv-audit](https://github.com/Zasnit1/osv-audit) | Check your dependencies against the OSV.dev vulnerability database and see which versions fix them |

Each is a single file, Python standard library only, tested, and MIT licensed.
